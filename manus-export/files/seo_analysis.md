# SEO & Naming Analysis for Chrome Web Store

## Competitive Landscape (Existing Extension Names)

### Direct Competitors:
1. **YouTube To Text** - 100K+ users, dominant for "youtube to text" keyword
2. **YouTube Transcript** - Strong for "youtube transcript" keyword
3. **YouTube Transcript AI Summary** - Targets "transcript AI summary"
4. **YouTube Text Tools - Video Transcript and Summary** - Long-tail SEO
5. **YouTube AI Math Transcriber – LaTeX, Markdown, PDF, TXT** - Only one using "Markdown" in name
6. **YouTube Summary & Transcript AI** - Targets "summary transcript AI"
7. **YouTube Transcript Generator** - Targets "transcript generator"
8. **YouTube Transcript Search** - Niche keyword search
9. **TubeOnAI** - Branded name, relies on description for SEO
10. **BibiGPT AI Watch Later** - Branded, summary-focused
11. **CaptionClip** - Branded, open-source
12. **Cpdown** - Branded, markdown-focused
13. **HoverNotes** - Obsidian integration focused
14. **Export YouTube Clips** - Clips/markdown generator

## Key Search Terms (High Volume):
- "youtube to text" - VERY HIGH
- "youtube transcript" - VERY HIGH
- "youtube video transcript" - HIGH
- "youtube summary" - HIGH
- "youtube to markdown" - MEDIUM (GROWING - AI agent use case)
- "youtube transcript AI" - MEDIUM
- "youtube transcript copy" - MEDIUM
- "youtube transcript download" - MEDIUM

## Gap Analysis:
- **"Markdown" is barely used** in extension names — only 1 competitor
- **"AI agent" / "skill" / "knowledge base"** — ZERO competitors target this
- **"MD" abbreviation** — unused, could be distinctive
- **"YouTube to Markdown"** — clear, descriptive, SEO-rich, unclaimed as primary name

## Name Candidates (Ranked by SEO Potential):

### Tier 1 — Best SEO + Unique Positioning:
1. **TubeMD — YouTube Transcript to Markdown & AI Skills**
   - "TubeMD" is brandable + "MD" in name
   - Description hits: youtube, transcript, markdown, AI, skills
   - Unique: only extension mentioning "skills"

2. **YouTube MD — Transcript to Markdown, Text & AI Summary**
   - Direct keyword match for "youtube" + "MD/markdown"
   - Covers all format keywords

3. **YT Transcript MD — YouTube to Markdown & Text**
   - Short, keyword-dense
   - "YT" is widely recognized abbreviation

### Tier 2 — Good SEO, More Generic:
4. **YouTube to Markdown — Transcript & AI Summary**
   - Most descriptive, best long-tail SEO
   - But longer and less brandable

5. **TubeScript MD — YouTube Transcript to Markdown**
   - Brandable, "Script" implies transcript
   - "MD" reinforces markdown

### Tier 3 — Branded, Needs Description SEO:
6. **ClipMD — YouTube to Markdown Transcript**
   - Short, memorable, Defuddle-like
   - "Clip" echoes Defuddle Clip

7. **TranscriptMD — YouTube Video to Markdown**
   - Very clear what it does
   - "TranscriptMD" is unique

## RECOMMENDATION:
**Primary: "TubeMD — YouTube Transcript to Markdown & AI Skills"**

Rationale:
- "TubeMD" is short, brandable, memorable, and contains "MD" (markdown)
- Subtitle hits the top 3 keywords: "YouTube", "Transcript", "Markdown"
- "AI Skills" is a unique differentiator no competitor has
- The full Chrome Web Store title would be:
  `TubeMD — YouTube Transcript to Markdown & AI Skills`
